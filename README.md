# AHC060
https://atcoder.jp/contests/ahc060/tasks/ahc060_a

---

## 問題概要

### 設定

- **N=100頂点・M辺**の連結な無向グラフ（2-辺連結）上を移動する
- 頂点は2種類：**ショップ** (頂点 0〜K-1, K=10) と **アイスの木** (頂点 K〜N-1)
- 初期状態では全ての木が W（バニラ）。行動2で W→R（ストロベリー）に変換可能（不可逆）
- 最大 **T=10000** ステップで行動する

### 行動

| 行動 | 条件 | 出力 | 効果 |
|------|------|------|------|
| 行動1: 移動 | 常に可能（2-辺連結） | 移動先頂点番号 | 木→コーンにW/Rを追加。ショップ→コーンの文字列を納品してコーンをリセット |
| 行動2: フリップ | 現在地が W の木 | -1 | その木を W→R に永続変換 |

**制約**: 直前の行動1の移動元には戻れない（バックトラック禁止）

### スコア

$$\sum_{i=0}^{K-1} |S_i|$$

（各ショップの在庫集合サイズの合計。同じコーン文字列を重複納品してもカウントされない）

**理論上限**: コーン長0〜10のパターン数 $\sum_{l=0}^{10}2^l = 2047$ 通り × K=10ショップ = **20,470点**

## 解法

### アルゴリズム全体像

**マルチスタート・ランダム化貪欲**：1試行 = T=10000ステップのシミュレーションを 1.9秒間繰り返し、最良スコアの行動列を出力する。

```
while elapsed < 1900ms:
    simulate(seed=trial_count) → (moves, score)
    if score > best: best = score, best_moves = moves
    trial_count++
output best_moves
```

### 事前計算: k-最短経路テーブル

```
precomp[v][s] = [(距離, 最初の移動先, 通過する木のリスト), ...]
```

- 全頂点 v × 全ショップ s について、**他のショップを経由しない最短単純路** を上位 K_PATHS=15 本列挙
- ビット付き優先度付きキュー（k-最短路アルゴリズム）で計算
- 通過する木のインデックス列を保持することで、**現在の ice_is_r 配列を参照して到着時のコーン文字列をアロケーションなしに事前予測**できる

### 各ステップの行動決定

優先順位：

```
1. 【行動2: W→Rフリップ】
   確率 FLIP_PROB=0.01 でフリップ（条件: 現在地が W の木 かつ フリップ残回数あり）

2. 【行動1: 移動先の決定】以下の優先順で選択:

   A. Greedy step（USE_GREEDY_BFS=true 時）
      precomp テーブルを参照し、「現在コーン + 経路上の木で作られるコーン文字列が
      まだそのショップに未納品」となる最短距離の (shop, path) を探す
      → そのパスの最初の1ステップを選択
      ※ バックトラック禁止・重複文字列スキップ考慮

   B. コーン長 ≥ MAX_CONE_LEN=10（コーンが上限に達した場合）
      → 隣接ショップがあれば weighted_next で選択
      → なければ多点BFS（未納品ショップを起点）で最近傍方向へ

   C. それ以外
      → weighted_next でランダムに次頂点を選択
```

`weighted_next` の重み：

$$w(v) = \left(\sum_{s=0}^{K-1} \frac{1}{d(v, s)}\right)^{\alpha}$$

（$d(v,s)$ はユークリッド距離、$\alpha$ = ATTRACTION_TEMP）

ショップに近い頂点ほど高確率で選ばれる（ATTRACTION_TEMP=2.0）。

### 内部表現の最適化（実行速度向上）

| 項目 | 変更前 | 変更後 | 効果 |
|------|--------|--------|------|
| コーン文字列 | `Vec<char>` | `(cone_val: u32, cone_len: u8)` ビットマスク | greedy ループのヒープ確保を完全排除 |
| 納品済み集合 | `BTreeSet<Vec<char>>` | `HashSet<u64>` | O(log n)→O(1) かつアロケーションなし |
| 木の種別 | `Vec<char>` (4byte/要素) | `Vec<bool>` (1byte/要素) | メモリ使用量1/4 |
| 隣接頂点リスト | 毎ステップ `Vec` 確保 | スタック固定配列 `[usize; 32]` | Vec アロケーション排除 |

これらにより試行回数が **140→696回** に向上（約5倍）。

### パラメータ

| パラメータ | 値 | 環境変数 | 説明 |
|---|---|---|---|
| `FLIP_PROB` | 0.01 | `FLIP_PROB` | 各ステップでW→Rフリップする確率 |
| `MAX_CONE_LEN` | 10 | `MAX_CONE_LEN` | コーン長の上限（超えたらショップへ急ぐ） |
| `K_PATHS` | 15 | `K_PATHS` | precomp に保持する経路数 |
| `ATTRACTION_TEMP` | 2.0 | `ATTRACTION_TEMP` | ショップ引力の指数（大きいほどショップに集中） |
| `TIME_LIMIT_MS` | 1900 | `TIME_LIMIT_MS` | 実行打ち切り時間（ms） |
